# Interactive Image Gallery

## About the Project
The Interactive Image Gallery is a responsive web application developed to display images in different categories. It allows users to explore images, search for specific pictures, and view them in an enlarged preview.

## Features
- Display images in multiple categories.
- Filter images by category.
- Search images by name in real time.
- View images using a lightbox preview.
- Responsive and user-friendly interface.

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Structure
```text
Interactive-Image-Gallery/

```

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
